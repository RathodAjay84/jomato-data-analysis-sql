Jomato Data Analysis using MSSQL
📌 Overview
This project focuses on analyzing restaurant data using Microsoft SQL Server (MSSQL). The goal is to extract meaningful insights from the dataset using SQL queries, functions, and aggregations.

🎯 Objectives

Perform data extraction and transformation using SQL
Analyze restaurant data to derive insights
Practice real-world data analysis using MSSQL


🛠️ Tools & Technologies

Microsoft SQL Server (MSSQL)
SQL (Structured Query Language)
VS Code


📊 Key SQL Concepts Used

SELECT statements
WHERE filtering
CASE statements
User-defined functions
Aggregate functions (SUM, COUNT, AVG)
GROUP BY & ROLLUP
Mathematical functions (CEILING, FLOOR, ABS)
Date functions (GETDATE, YEAR, DATENAME)
BULK INSERT (CSV data import)

🔍 Analysis Performed

Categorized restaurants based on ratings (Excellent, Good, Average, Bad)
Modified restaurant types using user-defined function
Analyzed cost distribution across restaurant types
Applied aggregation and rollup for summary insights
Used date and mathematical functions for data transformation


📈 Key Insights

Identified highly rated restaurants
Observed cost variations across restaurant categories
Derived structured insights from raw dataset using SQL
